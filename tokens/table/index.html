Settings

テーマごとの設定の表

各テーマで、意味の名前にどの値を当てているか、その値がどこから来たか（台帳のふだんの値か、そのテーマだけの値か）の表です。色は「色の名前」（主色・墨など 16 色）を指しているものが多く、色の名前ごとに、それを使っている名前の一覧も付けました。

値は、台帳 semantic.json とテーマの json から組み立てたもので、調整ページで試しただけの値は入っていません。
