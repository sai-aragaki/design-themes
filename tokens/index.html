Semantic tokens ／ 調整

意味の名前の調整

太字の線、章の番号、ボタンなど、本文の段落以外の見せ方 41 種類に付けた 70 個の名前を、Mint・Bold Yellow・SAI v2 の 3 列で同時に見比べ、その場で値を変えて試すページです。

見本は台帳（semantic.json）とテーマの json の値で描いています。記事やほかのページはまだこの名前を使っていません。このページ自体はテーマの切り替えの対象外です。

値を変えて、気に入ったら依頼にする

  1. 列の下の入力欄で値を変える（色は左の四角から選ぶか、#277A65 のように書く）。見本がその場で変わる
  2. 変えた値には「変えた値」の印が付く。↺ でその値だけ元に戻せる。入れた値はこのブラウザに残る
  3. 下の「プロンプトをコピー」で、変えた値だけを依頼の文にしてコピーし、HQ に貼る
